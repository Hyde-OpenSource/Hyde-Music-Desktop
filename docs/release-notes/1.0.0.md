The first release of **Hyde Music for Windows and Linux**: the same Liquid Glass design and pure-Dart engine as Hyde Music for Android, rebuilt for the desktop.

### Highlights
- **Desktop layout**: a Liquid Glass sidebar with search, sections and your playlists; a full-width glass player bar; lyrics and the queue open beside a large cover.
- **AI Shuffle**: a shuffle that flows (artist, album, length) and never plays more than two songs in a row by one artist. It's in the player bar, the queue and on every playlist and album.
- **Suggested Songs** under playlists. Click + to add one to your own playlist.
- **Synced lyrics**, word by word, with translation.
- **Home** with quick picks, mixes, moods, charts and new releases. Reload with F5.
- **Keyboard shortcuts**: Space, Ctrl+←/→, Ctrl+↑/↓, Ctrl+F, Ctrl+L, Ctrl+Q, Esc, and media keys.
- **Self-updating**: the Windows installer and the Linux AppImage update from GitHub releases, with checksum checks.

### Downloads
- **Windows 10/11**: `HydeMusic-1.0.0-windows-x64-Setup.exe` (or the portable zip)
- **Linux**: `HydeMusic-1.0.0-linux-x86_64.AppImage` (everything included) or the `tar.gz` (needs the system libmpv)

### Known limits
- Sign-in uses your browser's music.youtube.com cookie; there's no in-app login window on desktop yet.
- Windows SmartScreen may warn on first run: click More info › Run anyway.
- Not on desktop: system equaliser, local file scan, Nearby sync.
